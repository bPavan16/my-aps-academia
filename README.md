# Advanced Problem Solving (APS) Course Materials

This repository contains materials for the Advanced Problem Solving course at KLE Technological University, focusing on algorithmic techniques, competitive programming, and computational problem-solving approaches.

## 📚 About This Repository

APS (Advanced Problem Solving) teaches algorithmic thinking, optimization techniques, and problem-solving strategies essential for competitive programming and technical interviews. This repository stores class materials, assignments, and implementations of solutions to various algorithmic problems.

## 🗂️ Repository Structure

### Assignments
- Assignment problems and solutions organized by class sessions
- Documentation on problem-solving approaches
- Includes special topics like Birthday paradox analysis

### Class Files
- **APS-day1**: Introduction to problem-solving methodologies and PROMPTS framework
- **APS-day3**: Man-Machine Interface concepts and applications
- **APS-day4**: Data analysis techniques and practical implementations
  - Descriptive statistics worksheets
  - Indian pin codes dataset analysis
  - Algorithmic implementations including subset sum

### Code Implementations
- Various algorithmic solutions including dynamic programming approaches
- Data structure implementations
- Time and space complexity optimized solutions

### CSES Problem Set Solutions
Solutions to problems from the [CSES Problem Set](https://cses.fi/problemset/), organized by categories:
- Introductory problems
- Range queries
- Dynamic programming
- Graph algorithms
